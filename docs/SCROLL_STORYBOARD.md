# Landing page scroll storyboard

The landing page introduces the planner in eight scroll scenes. Motion uses
Framer Motion `useScroll`/`useTransform`, sticky scene content, and transform or
opacity changes only. Reduced-motion preferences disable the scroll transforms.

1. **Prompt** — A concise celebration pitch, prompt input, and three scenario
   buttons.
2. **Planning pile-up** — Chat, spreadsheet, and note cards give way to a single
   plan.
3. **One sentence** — A pinned, high-contrast statement explains the promise.
4. **Budget ring** — Scroll scrubs a visual allocation ring beside the budget
   message.
5. **Timeline** — A self-drawing milestone line demonstrates the planning
   schedule.
6. **Mood board** — A staggered grid gives a parallax impression of a shared
   visual direction.
7. **Panic Button** — A calm emergency-planning message previews what-if help.
8. **Maroon CTA** — A final high-contrast call to start planning.

Scenes remain readable and stacked on narrow screens; animation is decorative
and does not carry essential information.
